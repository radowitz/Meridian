# 快速上手：十分钟从零到能上网

前提都备好时，这一页大约十分钟走完。前提没备好（还没有服务器、路由器端口转发没做），先把它们准备好，时间不算在内。

## 开始之前

- **网关**：一台 Debian 13 主机（amd64 或 arm64，物理机或虚拟机都行），接在家里的局域网上，网卡已有静态地址，能以 root 登录。它和家里路由器在同一个网段。下面用文档地址举例：网段 `192.0.2.0/24`，路由器 `192.0.2.1`，网关 `192.0.2.88`。
- **远端服务器**：按你选的[拓扑模板](topologies.md)准备：至少一台境外出口；需要中继、枢纽或 IX 专线时另备。系统为 Debian 12 / 13（x86_64）或 Ubuntu 20.04（aarch64），能用 SSH 密码或私钥登录。
- **网络**：服务器在 NAT 后面时，路由器端口转发要提前做好（见 [FAQ](faq.md#nat-后面的中继要怎么转发端口)）。
- 不改家里路由器的配置，也不用停掉已经在跑的其他代理网关：Meridian 与它们并行，只有你把某台设备的网关和 DNS 指过来，它才经过 Meridian。

## 1. 安装（网关上，约 3 分钟）

```sh
git clone https://github.com/<owner>/meridian.git && cd meridian
sudo bash deploy/debian/install.sh --lan-addr 192.0.2.88 --version v1.0.2
```

- `--lan-addr` 是面板监听的局域网地址。不给时脚本会列出探测到的候选让你在终端确认。
- `--version v1.0.2` 从 `ghcr.io/radowitz/meridian` 拉取预构建镜像（amd64 / arm64）。网关连不上 ghcr.io 时，用 `--build` 在本机从源码构建，或在另一台机器上保存镜像再用 `--image-tar` 载入，见[安装网关](install.md#参数)。
- 脚本同时创建 DNS 分流用的 SmartDNS 容器 `meridian-smartdns`（compose 的 `dns` profile）：已有 `/etc/smartdns/smartdns.conf` 时当场启动并确认在运行；全新安装时只创建，第 4 步「安装到网关」写好配置后由 meridian-host 启动并等它应答。已在运行的容器不动；已存在但停止的容器，有配置时启动并确认在运行，没有配置时留给 meridian-host。本机已经装了宿主 `smartdns.service`（例如发行版的 smartdns 包）时，meridian-host 重启的是这个宿主单元而不是容器，脚本也就不创建、不启动容器；要改用容器，先停用并禁用宿主单元再重跑。SmartDNS 镜像来自 Docker Hub，网关拉不到时先在别处 `docker save` 再 `docker load`。
- 脚本结束时打印下一步命令。所有参数、重复运行和管理防火墙的说明见 [install.md](install.md)。

## 2. 取一次性初始化码（约 1 分钟）

```sh
sudo docker compose -f deploy/docker-compose.yml exec meridian meridian setup-code
```

面板**没有默认口令**。初始化码只显示在这个终端里，1 小时有效，输错 5 次作废。浏览器打开 `http://192.0.2.88:8787`，填入初始化码，创建管理员用户名和密码。安全模型见 [security.md](security.md)。

## 3. 首次配置向导（约 4 分钟）

创建管理员后面板进入向导（地址 `#/setup`），按顺序：

1. **网关**：确认局域网网卡、网关地址（带前缀长度）和主路由器地址。这些值只来自你的确认，面板不内置任何网段。
2. **选模板**：直连出口、单中继、中继 + 枢纽、IX 专线四选一，每种的样子见 [topologies.md](topologies.md)。
3. **服务器**：为模板里的每台机器填名称、地址、端口、用户和登录方式（密码或私钥），点「获取指纹」，**核对主机指纹**后「确认指纹并测试」。每台都要有 **WAN 网卡**（连接测试读到的默认路由网卡会预填，可改；读不到就手填，空着不能继续）。出口另填地区和公网 IPv4，并选默认地区（没有命中规则的境外流量去哪）。
4. **拓扑**：预览生成的拓扑和校验结果，没问题再保存。
5. **预检**：对网关跑一次只读预检，列出将要做的变更和与本机已有服务的冲突。有阻断项时按提示处理再重跑（见 [troubleshooting.md](troubleshooting.md#预检报告)）。
6. **安装**：打开「部署」页。向导自己不安装任何东西。

向导的进度保存在面板上，换浏览器或刷新都能接着走。**进度里不存任何秘密**：密码和私钥在第 3 步直接进入面板的凭据存储（单独的 `meridian-secrets` 卷），进度只记服务器 ID。

## 4. 部署（约 2 分钟加上远端下发时间）

在「部署」页按面板给出的顺序：远端预检 → 远端第一次下发（先远端、后网关）→ 网关预检 → 安装到网关 → 「名单」页更新一次名单。每一步之前都先列计划、要你确认，不满足前提的步骤会被拒绝并说明原因。

## 5. 让一台设备走 Meridian

在一台测试设备上手动把 **IPv4 网关和 DNS** 都改成 `192.0.2.88`，其他不动。打开一个境外网站，再打开一个国内网站：前者的出口 IP 应是你的出口服务器，后者应是你自己的宽带地址。

要撤回，把这台设备的网关和 DNS 改回路由器地址即可。
