## 这份记录没有覆盖的

- 真实的 IX、备用枢纽和出口；备用路径在测试里是 veth，不是 wstunnel 承载的 WSS；切回前的 120 秒冷却由带桩的单元测试覆盖，不在这里。
- 备用枢纽上没有 Mesh；有备用枢纽时只允许一台中继。
- 同一批提交里的其它改动（与已有业务共存的 DOCKER-USER 规则、开机单元、sysctl 范围、IPv6 路由通告、WAN 接口核对、面板下发的二进制）没有在任何真实主机上安装过。它们的预检部分在 2026-11-13 从面板对 11 台真实服务器只读执行过两次：第二次（包含上述改动的版本）有六台无阻断，其余的阻断是端口占用、节点配置了主机没有的 IPv6 出口、由用户态程序管理路由通告的主机，以及一台 Ubuntu 20.04 主机上的两处误报（版本号含 `~` 的 apt 候选被丢弃、ufw 单元处于 active 但 ufw 实际未启用），误报已在本次提交中修正，修正后没有重跑。新增的使用真实 iptables 的 `TestNetnsFwcompat` 没有运行过。
